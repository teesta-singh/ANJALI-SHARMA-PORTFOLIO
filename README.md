# Anjali Sharma Portfolio

A page-flipping web version of Anjali Sharma's interior design portfolio.

- `index.html` — the flipbook page
- `p/01.jpg` to `p/40.jpg` — the pages (01 is the front cover, 40 the back cover)

To update pages, export new JPGs from the PDF and replace the files in `p/` with the same names.
